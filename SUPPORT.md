# Support

- **Questions, ideas and deployment help:** [GitHub Discussions](https://github.com/genesary/ratelimit/discussions).
- **Bugs and feature requests:** [GitHub Issues](https://github.com/genesary/ratelimit/issues/new/choose), with the forms there.
- **Security vulnerabilities:** privately, as [`SECURITY.md`](SECURITY.md) explains.

The project has a single maintainer, so answers come on a best-effort basis. Before asking, the [documentation](docs/README.md) may already answer.
